v0.5.7

October 19, 2026 Release notes Download

Every phone you pair gets its own key and can be removed from your Mac, agents on your Linux servers show up next to the ones on your Mac, and the iPhone app gets a Home screen, widgets and Talk from Siri.

New

  • Paired phones. Settings → iPhone relay and the pairing sheet list every phone paired with this Mac and when it was last seen. Remove signs that phone out at once. On the phone, Settings → Unpair does the same from its side. Phones paired before this update keep working and show as one entry until you remove it.
  • Agents on your other machines. Settings → Agents → Other machines connects a Linux server over SSH: run the one command it shows on the server, then add the server's address. Its agents get dots on the toolbar, cards in the Inbox and rows in the panel, labelled with the server's name, and you can answer and prompt them from your Mac or your phone. Starting and ending agents on a server still happens on the server.
  • iPhone app 0.4.0 (in TestFlight): a Home screen that opens on what needs you, one-tap answers with a moment to undo, Home and Lock Screen widgets, and Talk from Siri, Shortcuts, Control Center and the Action Button.

Changed

  • Continue in the cloud is a TestFlight preview. It now appears only on Macs paired with a TestFlight build of the iPhone app, and it's off for new installs.
  • The phone's Talk receipt names the agent by what it's on, the way the Talk pill does.

v0.5.6

October 18, 2026 Release notes Download

Cadence's agents open as tabs in your own terminal app, the claude you type in any terminal can run through Cadence, and Talk picks its agent while you're still speaking.

New

  • Your terminal app. Settings → Agents → Open Cadence's agents in offers Terminal, iTerm or Ghostty. Automatic picks the one you run claude in most. In iTerm and Ghostty, agents from one folder share a window, one tab each, and clicking a dot brings its tab forward. Terminal still gives each agent its own window. Tabs are titled "claude-3 · keeps running in Cadence", because closing one leaves the agent running.
  • Your own terminals, through Cadence. Turn on Settings → Agents → Your own terminals, or say yes during setup. After that, claude, codex or pi typed in Ghostty, iTerm, Terminal or your editor runs through Cadence: it gets a dot on the toolbar, and you can answer it from the Inbox, by voice or from your phone. The terminal looks and works the same, and closing the tab ends the agent. It adds one line to ~/.zshrc, and you can turn it off any time.
  • More from your phone. This is the Mac side of the next iPhone app, which is in testing. Claude Code sessions in your other terminals show on the phone, and replying to a finished one moves it into Cadence. You can attach pictures to a reply, and see what an agent changed, file by file.

Changed

  • Talk decides as you speak. Talk starts working out where your words go at each pause, so it's ready when you let go. The pill names the agent before the request goes, and the request flies into that agent's dot. When you name an agent outright, your words go straight to it.
  • Sets in iTerm and Ghostty. Putting a set away closes its tabs, and opening it brings them back in the same window, order and place.

v0.5.5

October 16, 2026 Release notes Download

Dictation appears as you speak, updates install themselves, and Claude Code in your other terminals shows up on the toolbar.

New

  • Dictation types as you speak. Hold ⌥ and your words start appearing in the field about a second in, a few at a time. When you let go, Cadence swaps the rough text for the polished version in place, usually in well under a second. It works in native apps, browsers, Electron apps like Slack and VS Code, and terminals. Password fields never get text while you speak, and your clipboard is put back afterwards. Turn it off in Settings → Injection → Type as you speak.
  • Updates install themselves. Cadence checks 5 seconds after launch and then every 6 hours. When an update is out, the toolbar, the ⋯ menu and the Inbox say so, and Install and relaunch downloads it, checks its checksum, signature and notarization, swaps it in and reopens Cadence. This works from 0.5.5 on, so this update still installs the old way.
  • Claude Code from your other terminals. Claude Code sessions running in Terminal or iTerm show on the toolbar after a thin divider: blue while working, amber when asking you something, green when done. Click one to jump to that exact tab. The Inbox shows the question with Answer in Terminal, and finished sessions offer Move to Cadence.
  • Keep your Mac awake. In the toolbar's ⋯ menu: on, for 1 or 4 hours, or until your agents finish. A MacBook with its lid closed still sleeps unless it is plugged in with an external display.
  • Ready for the iPhone app. The Mac side of dictating replies, starting new agents, Talk, Keep awake, Inbox details and notifications from your phone. The iPhone app is in testing.

Changed

  • Faster polish. The on-device polish model now drafts ahead, about 40% faster on full sentences, with the same output.

Fixed

  • Quitting no longer crashes. Quitting from the menu, the Dock or a relaunch could crash in the speech model's teardown.
  • New agents in a new folder start properly. The first message no longer gets typed into Claude Code's "trust this folder?" prompt.
  • Talk keeps your terminal agents when herdr is slow, so "claude-9, …" reaches claude-9 instead of starting a new agent.

v0.5.4

October 14, 2026 Release notes Download

New

  • Anonymous usage counts, with a notice and an off switch. Cadence now sends a few anonymous counts so we can see which parts get used: first launch, app opened, onboarding finished, dictation, Talk results, Inbox answers by kind, and how many agents are running. Each count carries only the app version, never your text, file paths, agent names or an install ID. Nothing is sent until you've seen the notice (on onboarding's last step, or a one-time banner in the main window), and Settings → Updates → Share anonymous usage turns it off.

Fixed

  • The main window moves again. Since 0.5.0, dragging the main window (Feed, Notes, Log, Settings) by its title bar did nothing. You can now drag it from anywhere along the top bar.

v0.5.3

October 13, 2026 Release notes Download

New

  • The Inbox only asks when an agent is waiting on you. A card shows up only while an agent is stopped at a question, a permission prompt or a plan. Numbered lists in an agent's reply no longer turn into questions, the toolbar badge and the panel always agree, and a card you clear is cleared in every window.
  • Permission cards say what they're for. The command, file or address appears above "Do you want to proceed?", for example $ ping -c 2 127.0.0.1.
  • View plan. A plan card shows the plan's first lines and a View plan button (or press P) that opens the whole plan, formatted, inside the card.
  • Exact questions from Claude Code. Claude agents you start from Cadence report their questions and permission requests to Cadence directly, so options and descriptions appear exactly as Claude wrote them. "(Recommended)" only appears where Claude recommended something.
  • Menus without numbers get a card too, such as Claude's "trust this folder" check.
  • Type your answer instead. On a permission card, "yes", "ok" or "go ahead" approves; anything else declines and sends your words to the agent as its next instruction. Typed answers to Claude's questions and plans go through its own "Type something" and "Tell Claude what to change".
  • Finished work shows Claude's real last reply, one card per finished turn.
  • The toolbar folds into a notch. After 15 seconds untouched with nothing in the Inbox, the toolbar folds into a small notch on its edge that shows only the status dots. Hover or click it to open it up; anything new in the Inbox opens it too.
  • End all agents from the toolbar's agent list (from two agents up). The first click arms it and the second ends every agent listed, put-away sets included. The Director stays.
  • Stuck permissions fix. If System Settings shows Cadence switched on but Cadence says the permission is missing (an entry left over from an older version), Reset and relaunch clears it and reopens Cadence so macOS asks again. Granting Input Monitoring while Cadence is running now offers a relaunch to finish.

Fixed

  • Picking an answer on a question with several parts no longer skips the next part.
  • The buttons in the toolbar's ⋯ menu work on the first click.
  • The toolbar goes back to its edge after the displays sleep or the screen locks.
  • If sending an answer fails, its card stays in the Inbox.
  • A lighter look: the heavy drop shadows under panels and popovers are gone.

v0.5.2

October 13, 2026 Release notes Download

New

  • Ask Talk for a skill in plain words. Double-tap ⌥ (or press Talk) and say what you want, like "grill me on this plan" or "write this up as a doc". When one of your Claude Code skills does that, Cadence runs it on the agent it sends the request to, as /skill-name followed by your request. This works even for skills Claude never picks by itself.
  • Or name the skill. "Slash grilling, the router design", "use the grilling skill on the notch plan", or type /grilling … into the Talk pill. A request that names an agent ("claude-2, grill me on this") gets its skill too.
  • See what ran. The Talk pill shows the skill next to "Sent to …".
  • Cadence reads your skills from ~/.claude/skills, from the skills synced from claude.ai, and from a project's .claude/skills (for agents working in that project). Plain requests still go through as plain requests, and asking about or editing a skill does not run it.

v0.5.0

October 13, 2026 Download

Every coding agent, one inbox.

New

  • Talk. Double-tap ⌥ and say or type what you need. Cadence sends it to the agent already on that work, starts a new one, or answers through the Director, and shows a receipt of what it did.
  • Inbox. Questions and finished work from every agent in one place. Answer with 1 to 9, move with J and K, take an answer back within two seconds, or pick a suggested reply.
  • Terminal agents. Claude Code, Codex, OpenCode and other CLIs run in herdr terminals, shown in a real Terminal window. Every agent gets a short title, and a recap when it finishes.
  • A new toolbar. One dot per agent: blue is working, amber needs you, green is done. Hover to see what each one is on, and put a group of agents away as a set to reopen later.
  • Point at it. The camera button attaches a region of your screen to your next request.
  • Better dictation. Parakeet and hybrid transcription, Silero voice detection, better Text Polish and custom vocabulary.

Changed

  • Signed and notarized by Apple. Cadence opens like any other app. The new signature means macOS asks for permissions once more after updating; Installation explains how to reset them if they look stuck.
