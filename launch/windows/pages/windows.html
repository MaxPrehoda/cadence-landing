1 / Install

Run the installer

Open {{installer}}. It installs for your user only, so Windows doesn't ask for an administrator.

2 / Open

Nothing to grant

Windows has no permission screens for the keyboard or for typing. If Cadence can't hear you, turn on Settings → Privacy & security → Microphone → Let desktop apps access your microphone.

3 / Talk

Hold {{hotkey}} and talk

Hold it to dictate into any app. Double-tap it to send a request to the right agent.

Windows will warn you the first time. Cadence for Windows isn't code-signed yet, so the installer opens with "Windows protected your PC". Click More info, then Run anyway. Only do that for an installer you downloaded from this page or from our GitHub releases.

Which Windows do I need?

{{minOS}} on an Intel or AMD ({{arch}}) PC. That is what Cadence is built for and tested on. We haven't tested ARM PCs or older versions of Windows.

What do I need for agents?

The claude CLI for Windows, installed and signed in. Cadence uses that login, so there is no API key to set up. Dictation works without it.

Is Pro the same on Windows?

Yes. The same plans and the same license key: paste it in Settings → Pro. See pricing.

What about Cadence Pro?

Pro runs on the Mac today. On Windows it isn't ready yet, so everything Cadence does on Windows is free.

I'm on a Mac.

Download for Mac instead: Apple Silicon (M1 or newer) on macOS 13 or later.

What about Linux?

No Linux desktop app is planned. Agents running on your Linux servers show up in Cadence over SSH: see Run Claude Code on a remote server.
