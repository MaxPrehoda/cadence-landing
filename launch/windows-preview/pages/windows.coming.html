In the works / Windows

Cadence for Windows. We're building it.

Cadence runs on the Mac today. The Windows version isn't ready, and we won't guess at a date. Leave your email and you'll get one message, the day you can download it.

One email when it's ready. Nothing else.

The goal

The same app, not a smaller one

Every agent's questions and finished work in one Inbox, Talk to send a request to the right agent, and dictation that runs on your own PC.

Where it starts

Windows 11, on Intel and AMD PCs

That's the first build we're working toward. Anything beyond it comes after that one is solid.

What we can't tell you

A date, or what arrives first

We call a feature done once it has run on a real Windows machine, not before. Until then this page stays as it is.

Can I try a beta?

Not yet. There is nothing to download for Windows today. If that changes, this list is where we'll say so.

I have a Mac too. Can I start there?

Yes. Cadence is free on a Mac with Apple Silicon (M1 or newer) on macOS 13 or later, with no account. Download for Mac, or read the docs to see what it does.

What about Linux?

No Linux desktop app is planned. Agents running on your Linux servers already show up in Cadence on a Mac, over SSH: see Run Claude Code on a remote server.

What happens to my email?

It goes on this one list and is used for that one message. Want off it? Write to support@cadencevoice.ai and we'll remove you.
