Early preview / Windows

Cadence for Windows. An untested preview.

This is the first Windows build of Cadence. It was written and compiled without a Windows PC to try it on, so nobody has run it yet. If you install it, you are among the first. The Mac version is the finished one.

Before you download. Nothing in this build has been tested on Windows. It may not start. The installer is not signed, so Windows will warn you about it. Don't rely on it for real work yet.

Installer for Windows 11, x64 (Intel and AMD)

Install it

  1. Download the installer. Your browser may say the file "isn't commonly downloaded". Choose Keep.
  2. Run it. Windows shows a blue box, "Windows protected your PC", because the installer is unsigned. Click More info, then Run anyway.
  3. Open Cadence from the Start menu. It should walk you through setup and offer to download a speech model.
  4. To remove it: Settings, Apps, Installed apps, Cadence, Uninstall.

What we don't know

Everything else

"Should be there" means the code exists and compiles for Windows. It does not mean it works. The parts most likely to misbehave are the toolbar's position on screen, the Alt key on some keyboards, and anything typed into a window running as administrator, which Windows doesn't allow.

When something breaks

Please tell us. Write to support@cadencevoice.ai with what you did, what you expected and what happened, and attach the log file:

%LOCALAPPDATA%\com.cadence.app\logs\cadence.log

Paste that path into File Explorer's address bar to find it. The log stays on your PC unless you send it.

Is it safe to run an unsigned installer?

Unsigned means Windows can't check who made the file, so only install it if you downloaded it from this page or from the release page linked above. We don't have a code-signing certificate for Windows yet.

What do I need?

Windows 11 on an Intel or AMD PC. Windows on Arm and Windows 10 haven't been built for. For agents, Claude Code installed with its own Windows installer and signed in.

Is it free? Does Pro work?

The preview is free and needs no account, like the Mac app. Cadence Pro has not been tried on Windows, so don't buy it for this build.

I have a Mac too. Can I start there?

Yes. Cadence is free on a Mac with Apple Silicon (M1 or newer) on macOS 13 or later, with no account. Download for Mac, or read the docs to see what it does. The docs describe the Mac app.
