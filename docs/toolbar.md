# Toolbar

The toolbar is a thin strip on the edge of your screen. It shows what every agent is doing and gives you one-click access to the Inbox, Talk and dictation.

It sits on the right edge by default and stays above other windows, on every Space, including over full-screen apps.

## What's on it

From top to bottom (or left to right on a top or bottom edge):

| Part | What it does |
|---|---|
| **Inbox** | Opens the [Inbox](#/inbox). A badge shows how many agents are waiting for you, or how many finished if none are waiting. |
| **Agents pill** | One dot per agent. Click a dot to open that agent. |
| **Talk** | [Talk to your agents](#/talk). Hold it and speak, or tap to start and tap again to send. |
| **Mic** | Continuous [dictation](#/dictation) into the focused app. Click to start, click again to stop. |
| **Camera** | Capture a region of the screen. It is attached to your next message to an agent. |
| **⋯** | The toolbar menu. |

## Dot colors

| Color | Meaning |
|---|---|
| Blue, spinning | Working |
| Amber | Needs you: a question, a plan to approve, or a permission request |
| Green | Done |

When every agent is working, the dots run together into one blue bar.

Clicking a dot opens the agent where it lives. A Cadence chat agent opens in the panel next to the toolbar. A terminal agent opens in a Terminal window attached to its herdr session.

The pill shows up to eight dots. Past that, a **+N** dot opens the full list in the panel. [Sets](#/sets) keep the pill short.

## Peek

Hold the pointer on the agents pill for two seconds. On a side edge the pill widens and shows a line beside each dot: the agent's title, what it is on, and how long ago it last did something. A quick glance does nothing, so the pill does not pop open every time you pass it.

While peeking you can also:

- Click the trash icon on a row to end that agent. The first click arms it, the second click ends it.
- Click **Put away as a set** to fold your agents into a [set](#/sets).
- Click the **+** row (for example **New Claude Code in my-app**) to start another agent of the kind you use, in the folder you used last.

## The ⋯ menu

- **Open Cadence**: the main window with Feed, Notes, Log and Settings.
- **Agents board**: the larger dashboard, with **Chat** and **Board** modes. Cards show each agent's branch or worktree and its diff.
- **New agent…**: start an agent. See [Agents and CLIs](#/agents-and-clis).
- **Take Cadence with you…**: pairing for the iPhone app, which is not available yet. See [iPhone](#/iphone).
- **Edge of the screen**: Top, Right, Bottom or Left.
- **Display**: which display the toolbar lives on (only shown with more than one).
- **Hide for a while**: 10 min, 1 hour or Today.
- **Hide the toolbar**: hide it until you turn it back on in **Settings → About → Show floating indicator**.

The toolbar stays on the display it started on. It only moves if you pick another display or that display is disconnected.
