Introducing Cadence Drive.

One folder, the same on every computer you've paired with Cadence and on your iPhone. Your agents write to it, you see who wrote what, and edits merge on their own.

By Cadence Labs · Filed in Product · Cadence 0.12.0

§01 Agents on two computers, and no place to put a file

Since 0.11, Cadence can pair your computers. From the laptop on the couch you can see the agents on the desktop in the other room, read what they're doing and answer their questions.

That made one gap obvious. The agents could see each other, but they couldn't hand each other anything. An agent on the desktop writes up the payment API. An agent on the laptop needs those notes. So you paste them into a chat, or push a branch whose only job is to carry one text file, or email them to yourself. Then two agents edit the same notes, and one of them quietly wins.

We wanted one place for files that every agent on every computer can use, without a new tool for any of them to learn.

§02 What we built

Cadence Drive is a folder: ~/Cadence Drive. Turn it on in Cadence on one computer and it appears in your home folder. Turn it on on a second computer you've paired and that one joins the same drive. A file you put in on one is on the others.

It's an ordinary folder. Finder opens it, your editor opens it, and an agent writes to it with the same file tools it uses for everything else. Nothing needs a plugin.

The iPhone app, which is in a TestFlight beta, gets a Drive tab with the same live view. You can read any file and answer a collision from there. The share sheet has Save to Cadence Drive, so a screenshot, a photo or a PDF goes straight into the drive, with an optional note to an agent.

Cadence Drive is part of Cadence Pro, at no extra charge.

§03 Who wrote what

A folder that five agents write to gets confusing fast unless you can see who is doing what. So Cadence credits each change to the agent that made it. It follows the file edits of Claude Code sessions, and Claude Code agents that Cadence starts also get four Drive tools of their own: drive_list, drive_read, drive_write and drive_search.

While an agent writes, the toolbar shows a ring in that agent's colour. The Drive view in Cadence's panel lists the files being written right now, with the text arriving as the agent writes it.

Open a file and a coloured edge runs down its side. Each colour is an agent, or you. A history bar replays the file version by version, and you can restore any of its last 200 versions.

§04 How edits merge

Most of the time two agents touch different parts of a file. Those edits combine on their own. If one agent fixes a heading and another adds a paragraph at the end, the file has both. CSV and TSV files merge row by row, so two agents adding rows to one table both get their rows in.

Sometimes two agents change the same lines. Then a card arrives in the Inbox, on your Mac and on your iPhone. It shows both sides, and above them a combined version that Claude wrote from the two. You can keep the combined version, keep either side, or keep both as separate files. Like every answer in the Inbox, the choice waits two seconds so you can undo it. Then both agents get the result, so neither keeps working from a version that's gone.

We put collisions in the Inbox on purpose. Two agents disagreeing about the same sentence is a question only you can settle, and the Inbox is where Cadence already puts those.

§05 Private from us too

Cadence's relay stores the files for your other devices, and it only ever has sealed copies. Each file is encrypted on the device that wrote it, with AES-256-GCM and keys that only your devices hold. The file's name is sealed too. The relay stores the files, but it can't read what's in them or what they're called.

§06 The rest of it

  • Trash. Delete a file here or on another device and it waits in the Trash for 30 days.
  • Briefs. When an agent finishes, its recap is saved in briefs/. The next agent, on any computer, reads it and picks up where the last one left off.
  • A file browser in the panel. Folders, list or grid, and columns you can sort by who changed a file, when, and its size. Right-click to open, show in Finder, copy the path, rename, move, duplicate, see version history, hand it to an agent, or move it to the Trash. Drag files in.
  • Search. Every text file in the drive, by plain words or a regular expression.
  • Talk. Double-tap ⌥ and say "Give the checkout agent the API notes", "Put my clipboard in the drive as launch copy" or "What changed in the drive today?".

Two limits: a file can be up to 512 MB, and an empty folder syncs once a file is in it.

§07 Try it

Cadence Drive is in Cadence 0.12.0. Update from inside the app or download it, then turn it on in Settings → Agents → Cadence Drive. Do the same on your other computers and they join the same drive. The Cadence Drive page has the details, and Pro is $20 a month, $200 a year, or $249 once for the first 100.

If something doesn't merge the way you expected, write to support@cadencevoice.ai. A person reads every email.
