Offline dictation on a Mac on-device speech to text, no internet needed

You can dictate on a Mac without your voice leaving the machine. This guide compares the built-in options with apps that run a speech model locally, and covers what matters when you dictate code, names and prompts.

Last updated: October 19, 2026 · Cadence Labs

Short answer

Turn on Dictation in System Settings → Keyboard. On Apple Silicon Macs, Apple processes dictation on device for many languages, and Keyboard settings say whether yours is one of them. If you need custom vocabulary, hold-to-talk in any app, or control over which model runs, use an app that runs a speech model such as Whisper or NVIDIA Parakeet on your Mac.

To check that dictation is really offline, turn off Wi-Fi and try it.

Option 1: macOS Dictation

Every Mac has dictation built in.

  1. Open System Settings → Keyboard and turn on Dictation.
  2. Pick a Shortcut, for example pressing the Globe key or Control twice.
  3. Click into a text field, press the shortcut and speak.

On Apple Silicon, Apple says dictation requests are processed on device for many languages; some languages and features may still use Apple's servers. The Dictation section of Keyboard settings tells you whether yours is processed on your device, and Apple's dictation help has the details. It adds punctuation as you talk, costs nothing and needs no install.

For coding, the gaps are vocabulary and control. There is no list where you teach it your repo names, library names or teammates' names, and you cannot choose the model.

Option 2: Voice Control

System Settings → Accessibility → Voice Control is Apple's full hands-free control system. It runs on device and has a Vocabulary list for custom words. It is built for controlling the whole Mac by voice, so it listens for commands all the time it is on and takes some learning. It is a good fit if you want hands-free use; it is heavy if you only want to dictate a paragraph now and then.

Option 3: apps with local speech models

Open speech models now run fast on Apple Silicon. OpenAI's Whisper and NVIDIA's Parakeet are the common ones. Apps built on them download the model once and transcribe on your Mac from then on. When you compare them, look at:

  • Where it runs. Local by default, with any cloud step clearly optional.
  • Push-to-talk in any app. Hold a key, speak, release, and the text lands at the cursor, including in terminals and editors.
  • Custom vocabulary. A way to add names and jargon so pnpm does not come out as "PNPM" or "p and p.m."
  • Latency. How long after you let go the text appears. Anything over a second breaks your flow.
  • Silence handling. Some models invent words when they hear only a fan or keyboard noise.
  • Cleanup. Punctuation and filler-word removal, ideally local too, with a way to turn it off for terminals.

How to check it is offline

Turn off Wi-Fi, unplug Ethernet, and dictate a sentence. If text still appears, transcription is local. Then read the app's privacy page for what it sends when you are online; downloading a model or checking for updates needs the network even when transcription does not.

Dictation in Cadence

Cadence is a free macOS app for running coding agents, with on-device dictation built in. Dictation works without any agent setup.

Set it up

  1. Download Cadence and grant Microphone, Accessibility and Input Monitoring during onboarding.
  2. Choose your hotkey. Option (⌥) is recommended; change it later in Settings → Hotkey → Push-to-Talk Key.
  3. Download the speech model when asked: Parakeet v2, about 630 MB. After that, transcription needs no network.

Use it

Click into any text field, hold ⌥, and speak. Your words start appearing about a second in, a few at a time, and when you let go Cadence swaps the rough text for the polished version in place. It works in native apps, browsers, Electron apps like Slack and VS Code, and terminals. Password fields never get text while you speak, and your clipboard is put back afterward. To have the text arrive only on release, turn off Settings → Injection → Type as you speak. A quick tap, or a shortcut like ⌥←, types nothing. For long passages, click the mic button on the toolbar to dictate continuously.

Cadence keeps the half second before you press the key so your first word is not clipped, finds speech with Silero VAD, and transcribes each piece at the next pause while you are still holding the key. On Cadence's own test set this measured 1.88% word error rate on clean read speech and about 330 ms from release to text at the 95th percentile. For other languages, pick Parakeet v3 (25 languages) in Settings → Models.

Teach it your words

Add names and jargon in Settings → Commands → Vocabulary; the model is primed with them, and your agents' names are added automatically. With a Whisper Large v3 Turbo model downloaded, Cadence double-checks words that might be from your vocabulary. If a phrase is always heard wrong, add a rule in Settings → Commands → Auto-Corrections.

Text Polish

Text Polish fixes punctuation, capitalization and filler words with Qwen 2.5 1.5B running on your Mac (a separate download of about 1.1 GB, in Settings → Injection → Text Polish). Set a tone per app in Settings → AI → App Tone Profiles; use Raw (no polish) for terminals. Cloud Polish is optional, off by default, and sends text (never audio) to Anthropic with your own API key.

What stays on your Mac

Audio, transcription and Text Polish run locally, and audio is not uploaded. The microphone stays open while Cadence runs so the first word is not cut off; that half second lives in memory and is thrown away unless you press the hotkey. Details are on the privacy page.

The same key also talks to your coding agents: a double-tap of ⌥ opens Talk instead of dictating. Plain dictation never goes to an agent. The voice control guide for Claude Code compares this with Claude Code's own /voice, which sends audio to Anthropic for transcription.

Common questions

Does macOS Dictation work offline?

On Apple Silicon Macs, Apple processes dictation on device for many languages, so it works offline for those. Turn off Wi-Fi and try it to confirm for your language.

Does Cadence dictation need an internet connection?

Only to download the speech model the first time. Transcription and the local Text Polish model run on your Mac. Agent features need the network, since they talk to Claude.

Which Macs does Cadence dictation run on?

Macs with Apple Silicon (M1 or newer) on macOS 13 or later. There is no Intel build.

Hold ⌥ to dictate into any app, transcribed on your Mac. Free, no account. macOS 13 or later on Apple Silicon.
